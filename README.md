# Comparaci-n-de-Walmart-e-IBM-precios-de-cierre-en-las-acciones-
Se comparan los precios de cierre de IBM y Walmart de septiembre de 2021 a septiembre de 2026.


El proyecto comparó los precios de cierre de IBM y Walmart de septiembre de 2021 a septiembre de 2026 (1,254 datos diarios). Sus precios tienen una correlación alta (0.93), pero sus rendimientos diarios casi no se relacionan, así que comparten tendencia de largo plazo, no movimientos día a día. Ambas series no fueron estacionarias y lo lograron con una primera diferencia. Con una media móvil de 5 días se pronosticó el siguiente día: ~227.48 dólares para IBM y ~108.99 para Walmart. El error fue mayor en IBM (RMSE = 6.91) que en Walmart (RMSE = 1.76), por ser más volátil, y al ser un método simple, no capta cambios bruscos.
